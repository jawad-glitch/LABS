# Common pull request merge strategies

## Merge commit
Combines the feature branch and preserves its branch history.

## Squash and merge
Combines the pull request commits into one commit on the target branch.

## Rebase and merge
Replays commits onto the target branch to create a linear history.

Maintainers choose the strategy according to the repository's contribution policy.
A contributor should not assume that an unapproved pull request has been merged.
