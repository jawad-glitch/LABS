# Introduction to FDC3 - Local Lab

This project implements a local mock FDC3 Desktop Agent using Node.js, WebSocket and Express.

## Services
- Desktop Agent: ws://localhost:4200
- Research App: http://localhost:3001
- Chart App: http://localhost:3002
- Trading App: http://localhost:3003

## Run
Start the agent and three apps using the lab launcher or separate terminal sessions.
Run tests with `npm test`.

## Scope
This is a learning simulation of context broadcasting, channel isolation, listener management, application metadata and intent routing. It is not a certified FDC3 Desktop Agent and does not provide full interoperability conformance.
