# Blockchain Fundamentals

## What is Blockchain?
- A distributed, immutable ledger technology
- Chain of blocks containing transaction data
- Cryptographically secured using hash functions
- Decentralized network of nodes maintaining consensus

## Key Characteristics:
1. **Immutability**: Once data is recorded, it cannot be altered
2. **Transparency**: All transactions are visible to network participants
3. **Decentralization**: No single point of control or failure
4. **Consensus**: Network agreement on transaction validity
5. **Cryptographic Security**: Hash functions and digital signatures

## Distributed Ledger Technology (DLT):
- Broader category that includes blockchain
- Shared database across multiple locations
- No central administrator or centralized data storage
- Each node maintains identical copy of ledger
