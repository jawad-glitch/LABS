Deviations from lab text
------------------------
1. **Besu started with --network=dev** instead of the lab's PoW genesis + --miner-enabled.
   Rationale:
   - Lab genesis has difficulty=0x10000 with ethash; first block requires generating
     a 1GB DAG and CPU ethash at this difficulty gives >30s/block.
   - PoW mode returns empty eth_accounts, so Truffle cannot sign transactions
     (Truffle needs unlocked accounts from eth_accounts).
   - --network=dev is Besu's documented local-development mode: instant blocks,
     unlocked prefunded accounts, full Truffle compatibility.
2. **Chain ID is 2018 (dev mode default)**, not 1337. Cosmetic - all contract
   behavior, RPC methods, and tooling work identically. truffle-config.js uses
   network_id: "*" to accept it.
3. **truffle init skipped**, files created manually (Migrations.sol + migrations).
   Avoids any network fetch / interactive step. Content is identical to what
   truffle init would generate.
4. **truffle console replaced with truffle exec** for automation. Both execute
   the same set/get/increment/getInfo calls against the same deployed contract.
