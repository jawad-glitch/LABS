# CDM Regulatory Reporting Use Case

## Scenario
An organization processes derivatives trades and needs consistent transaction data for downstream systems.

## Illustrative workflow
1. Capture trade information.
2. Represent relevant product and transaction details using CDM concepts.
3. Validate data against the applicable model rules.
4. Map the information to the formats required by downstream systems.
5. Apply jurisdiction-specific reporting rules before submission.

## Benefits
- More consistent transaction representation.
- Reusable data definitions.
- Potentially simpler integration and transformation.

CDM does not automatically generate legally compliant regulatory submissions without the required reporting logic and controls.
