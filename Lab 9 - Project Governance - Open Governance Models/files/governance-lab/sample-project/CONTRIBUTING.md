# Contribution Guide

1. Open an issue describing the problem or proposed improvement.
2. Create a focused branch for your change.
3. Keep changes small and include tests where appropriate.
4. Run the test suite before submitting.
5. Submit a pull request with a clear explanation.
6. Respond respectfully to review feedback.

All participants must follow the project's code of conduct.
Significant architectural changes should be submitted as RFCs.
