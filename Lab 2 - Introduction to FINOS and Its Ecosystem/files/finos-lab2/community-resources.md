# FINOS Community Resources

## Useful starting points
- FINOS website: https://www.finos.org/
- FINOS GitHub organization: https://github.com/finos
- FINOS community repository: https://github.com/finos/community
- FDC3 repository: https://github.com/finos/FDC3
- Common Domain Model repository: https://github.com/finos/common-domain-model

## Ways to participate
- Read project documentation and contribution guidelines.
- Review issues and discussions.
- Attend public project meetings where available.
- Contribute documentation, tests, or code.
- Follow the project's code of conduct and review process.

Check each project's current README for its active communication channels and meeting details.
