# Financial Services Industry Challenges Addressed by FINOS

## Desktop application silos — FDC3
### Challenges
- Applications may operate independently.
- Users may re-enter the same instrument or entity information.
- Workflows can differ between applications.
- Manual transfers can introduce operational errors.

### FDC3 approach
- Standardized context data.
- Intent-based application interactions.
- Desktop Agent-mediated communication.
- Shared workflows across compatible applications.

## Data model inconsistencies — CDM
### Challenges
- Organizations may represent similar transactions differently.
- Integrations require mapping between data formats.
- Data quality can vary between systems.
- Lifecycle processing can be difficult to standardize.

### CDM approach
- Shared financial-domain definitions.
- Model-based validation and tooling.
- Consistent representation of products and events.
- A common basis for system integration.

## Open standards
Open collaboration can reduce dependence on proprietary interfaces and encourage interoperable implementations. It does not eliminate the need for implementation testing, governance, or vendor-specific integration.
