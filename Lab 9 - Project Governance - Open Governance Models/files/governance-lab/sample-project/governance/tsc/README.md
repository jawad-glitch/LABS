# Technical Steering Committee

The TSC provides strategic oversight and resolves escalated technical or governance
decisions. Membership and appointments must be documented transparently.

## Responsibilities
- Review strategic RFCs.
- Resolve governance disputes.
- Maintain project direction.
- Publish decisions and meeting records.
