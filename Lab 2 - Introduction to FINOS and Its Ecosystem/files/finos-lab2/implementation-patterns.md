# FINOS Implementation Patterns

## FDC3

### Desktop Agent integration
Applications connect to a Desktop Agent and use supported FDC3 APIs for context and intent communication.

### Browser-based integration
Web applications can participate when supported by the relevant desktop environment and integration approach. Browser messaging alone is not proof of FDC3 conformance.

### Application capabilities
Applications expose or handle supported intents and context types so other applications can discover and interact with them.

## CDM

### Model-driven development
Define or consume financial concepts using the CDM model and Rosetta tooling.

### Validation
Validate data against the applicable model definitions and rules.

### Integration
Map between CDM representations and organization-specific or external system formats. Test transformations carefully, especially where regulatory reporting is involved.
