# RISC-V Architecture Evaluation

## Project and Standard
- Name: RISC-V
- Type: Open instruction set architecture standard
- Origin: University of California, Berkeley
- Started: 2010
- Standard organization: RISC-V International

## Evaluation
- Open specification: Yes
- Modular architecture: Yes
- Standard extensions: Yes
- Custom extensions: Supported
- Processor implementations: Available from multiple vendors

## Learning Focus
- Base integer ISA
- Standard extensions
- Cross-compilation
- Emulation with QEMU
- Assembly and disassembly
