# FINOS Contribution Review Checklist

## Technical
- [ ] Change has a clear purpose and limited scope.
- [ ] Code follows the project's conventions.
- [ ] Tests cover relevant behavior.
- [ ] Documentation is updated.
- [ ] Security and performance implications were considered.

## Project requirements
- [ ] Contribution guide has been followed.
- [ ] Required license or Developer Certificate of Origin steps are complete.
- [ ] Compatibility implications have been considered.
- [ ] CI checks pass.

## Review and merge
- [ ] Commit messages are clear.
- [ ] Reviewer feedback has been addressed.
- [ ] Required approvals have been obtained.
- [ ] Maintainers have completed the project's merge process.
