# Contribution Plan: FINOS Perspective

- Repository: https://github.com/finos/perspective
- Read CONTRIBUTING.md and DEVELOPMENT.md
- Review open issues and recent pull requests
- Create a feature branch from the current upstream default branch
- Make a focused documentation change
- Validate Markdown and inspect the final diff
- Push to the personal fork and open a pull request
- Respond to maintainer feedback and complete applicable FINOS agreements
