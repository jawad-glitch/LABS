ROW SUM OPTIMIZED LOOP
The loop processes four matrix elements per iteration, with two iterations covering one eight-element row.
Disassembly:

The baseline recalculates row and column offsets in the innermost loop. The optimized implementation hoists the matrix base address and advances the row pointer by fixed increments.
Four independent accumulators collect separate column lanes and are combined after the unrolled loop.
A load-use hazard remains in the pair  followed by ; the add consumes the value produced by the immediately preceding load.
These are potential load-use hazards on a simple in-order pipeline. Actual stall behavior depends on the implementation's forwarding and interlock logic.

MEASUREMENT LIMITATIONS
The profile frequency tables are static instruction counts. They do not reveal dynamic loop-branch executions or dynamic memory operations.
The unrolled code can contain more static lw and mul instructions while executing fewer loop iterations.
QEMU user-mode wall-clock measurements are not cycle counts and are sensitive to host scheduling and timer resolution.
