# FINOS Governance and Contribution Summary

## Governance
FINOS projects operate under documented foundation and project governance processes. Consult the current FINOS governance documentation and the individual project's governance files for authoritative details.

## Typical participant roles
- Foundation governance bodies and committees.
- Project maintainers.
- Contributors.
- Users and participating organizations.

## Contribution types
- Code and bug fixes.
- Documentation and examples.
- Tests and quality improvements.
- Standards proposals and reviews.
- Community support.

## Contribution workflow
1. Read the project's contributing guide and code of conduct.
2. Review open issues and project priorities.
3. Discuss substantial changes with maintainers before implementation.
4. Fork the repository and create a focused branch.
5. Make changes and add tests or documentation.
6. Run the project's required checks.
7. Submit a pull request and respond to review feedback.

Project-specific requirements take precedence over this general summary.
